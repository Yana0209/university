# Розробка системи управління контентом з типобезпечною архітектурою

## Мета роботи

Спроектувати систему типів для платформи управління контентом (CMS) з використанням просунутих можливостей TypeScript.

## Опис

Цей проект реалізує систему управління контентом (CMS) з типобезпечною архітектурою, яка включає:

1. **Базову структуру для різних типів контенту**: реалізовані інтерфейси для базового контенту та конкретних типів (статті, продукти).
2. **Систему управління правами доступу**: реалізовані ролі та права для роботи з контентом.
3. **Систему валідації**: перевірка даних контенту за допомогою валідаторів та композитних валідаторів.
4. **Систему версіонування контенту**: відслідковування змін у контенті та підтримка версій.
