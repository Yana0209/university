#PR7
## Мета роботи
Набути практичних навичок роботи з TypeScript, зокрема з використанням Enum, через створення системи управління навчальним процесом університету.

---

### Опис проєкту
Цей проєкт реалізує систему управління університетом, що дозволяє:
- Реєструвати студентів.
- Реєструвати студентів на курси.
- Призначати оцінки студентам.
- Оновлювати статус студентів.
- Виводити списки студентів, доступних курсів, та оцінок.
