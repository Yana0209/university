# E-Commerce System with TypeScript Generics

## Purpose
This project explores the fundamentals of TypeScript generics, focusing on creating type-safe functions for managing products in an e-commerce setting.

## Objectives
- Understand and implement generics in TypeScript
- Create type-safe functions for handling product data
- Build basic functionality for an e-commerce system, working with various product types

### Requirements
- Type-safe functions
- Only functional programming (no classes)
- Input validation for all functions
